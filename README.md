# Pit Wall - GP de São Paulo 🏎️🏁

Projeto desenvolvido como desafio prático de **Linguagem de Marcação (HTML e CSS)**, simulando a página oficial do Grande Prêmio de São Paulo de Fórmula 1 em Interlagos.

## 🚀 Tecnologias utilizadas
* **HTML5**: Estruturação semântica da página (cabeçalho, seções de pilotos, tabela de classificação e formulário de ingressos)[cite: 5, 13].
* **CSS3**: Estilização visual completa com paleta de cores personalizada, fontes do Google Fonts, efeitos de `hover` e responsividade para dispositivos móveis[cite: 3, 4, 7, 8, 9, 11, 13].

## 🛠️ Conceitos aplicados
* `:root` e variáveis CSS (`var()`)[cite: 4, 8]
* `display: flex` para alinhamentos e barra de navegação[cite: 2, 4, 9, 10]
* CSS Grid e `auto-fit` para os cards dos pilotos[cite: 2, 4]
* Estilização avançada de tabelas (`<table>`, `<thead>`, `<tbody>`)[cite: 4]
* Design responsivo com `@media queries` para celulares e tablets[cite: 2, 4, 11, 12]
